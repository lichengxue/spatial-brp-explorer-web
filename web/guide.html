Try your first comparison

  1. The opening example uses natal homing, directional movement and a 40% SPR target. It calculates automatically.
  2. Inspect biomass, catch and fishing mortality. Click a legend entry to highlight its curve; overlapping curves are expected for equivalent methods.
  3. Open BRP comparison to compare F₁, F₂ and population/regional SPR.
  4. Use Model settings to change population structure, recruitment, seasonal movement, surveys, fishing pattern or biology at age.
  5. Choose reference points on the left and click Calculate & project. The default SPR target is 40%; other percentages are available.
  6. Use Export results for a ZIP containing settings, annual trajectories and reference-point tables. Copy a scenario link to share a preset.

What the choices mean

Global methods solve one fishing multiplier at a fixed F₁:F₂ ratio. Population methods target spawning potential by birth origin. Regional methods combine the origins spawning in each region using the selected weights.

“Without movement” changes the reference-point calculation. The population projections retain your actual movement settings. Surveys occur at each season midpoint in both regions; selected historical indices determine survey weights.

Yield-SPR searches for the highest equilibrium catch with both regional ratios at least your SPR target. Under Beverton–Holt recruitment, Yield-Max is the joint system MSY comparison. Optional yield searches take longer than SPR calculations.

An unavailable target means the numerical solver did not find an accepted solution within its bounds. Yield/MSY results are bounded numerical maxima; they do not establish uniqueness. Open the Equations tab for definitions and calculation details.

Use the R code

Download the commented R scripts. Extract them, set the folder as your R working directory and run source("run_example.R"). Edit parameters.R for biology and movement, and run_example.R for target, fishing pattern and methods. Only base R is required.

The web app executes the same R model as the local GUI using WebR. Reloading the page clears your session; export results you want to keep. Read the source and README on GitHub.
